## 🌟 Repository Overview

Welcome to the **Complete JavaScript Notes** repository! This repository is designed for developers, students, and job seekers aiming to master JavaScript deeply for frontend, MERN stack, or Node.js backend roles.

Every topic features **bilingual explanations (English + Thunglish)**, practical code examples, common traps, interview questions, and fully-solved coding problems.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jeromelarens/Javascript-Notes.git
cd Javascript-Notes
```

### 2. Explore Level 1

```bash
cd Javascript-Level-1
node index.js
npm test
npm run project
```

### 3. Explore Level 2

```bash
cd ../Javascript-Level-2
node index.js
npm run test:projects
npm run predictions
```
